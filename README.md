# Gnomopocalypse
Gnomopocalypse — командный jam-prototype 2D pixel-art action game, 
собранный на Unity 6.

## Project status

Проект завершён как игровой prototype для game jam и содержит:

- BootstrapScene, MenuScene и 2 игровых уровня
- глобальный и level state flow
- конфиг-драйвен спавн юнитов и projectile loop
- pause / win / lose logic
- audio system
- Web build profiles для development и release
